THE LINE

Preparing a return is not filing it

The brief says filing stays with the owner or a professional and is simulated in the hackathon. We built it that way.

  • Agents hold only stage and get. No file, authorize or otp tool can be registered
  • A single-use OTP is bound to the SHA-256 of the exact bytes the owner saw
  • Edit the draft after approving and the OTP is void
  • The GSP path saves a draft only and never files
  • Every step lands in a hash-chained audit log
