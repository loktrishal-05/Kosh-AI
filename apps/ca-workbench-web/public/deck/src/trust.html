SYSTEM DESIGN

Why a regulator, a CA and an owner can all trust it

Six design rules, each enforced in code and covered by automated tests (900+ Python, 43 workbench).
1

Neuro-symbolic split

The model reads and drafts. The deterministic engine does every rupee of arithmetic and has no LLM import.

2

Agents cannot file

Agents get stage and get. The tool mesh refuses to register anything named file, authorize or otp.

3

Non-repudiation

OTP is single-use and bound to SHA-256 of the payload. The portal re-checks an HMAC token. Audit events are hash-chained.

4

Exact money

Decimal end to end, HALF_UP rounding, money serialised as strings so a float never touches a rupee.

5

No invented law

A citation counts only if it resolves in the effective-dated statute corpus. Circular relief unlocks through a deterministic gate first.

6

Isolation in the database

Postgres FORCE row-level security keyed on tenant, with a non-bypass application role. App bugs cannot leak across firms.
